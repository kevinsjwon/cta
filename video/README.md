# 유튜브 영상 작업 (video)

세무 관련 유튜브 영상을 만드는 작업 폴더입니다.
캐릭터 이미지와 음성을 이용해 입 모양이 맞춰진(립싱크) 영상을 만드는 과정을 정리합니다.

## 중요 안내 — 아직 실제 자료가 필요합니다

이 문서는 현재 **틀(템플릿)** 입니다.
사용자님이 이미 가지고 계신 아래 자료들이 이 저장소에 아직 올라와 있지 않기 때문입니다.

- 기존에 완성한 영상
- 영상 제작에 사용한 캐릭터 이미지들
- 작업 프로세스를 정리한 파일

> 이 자료들은 사용자님 컴퓨터의 `Desktop/lipsync-pipeline` 폴더에 있는 것으로 이해했습니다.
> 이 프로젝트는 클라우드에서 동작하므로 개인 컴퓨터의 Desktop 폴더에는 접근할 수 없습니다.
> 아래 "자료 전달 방법"을 참고해 자료를 올려 주시면, 실제 프로세스에 맞게 이 문서를
> 구체적으로 다시 정리하고, 새 캐릭터 이미지로도 **같은 구도의 영상**을 만들 수 있는
> 재현 가능한 가이드로 완성하겠습니다.

## 자료 전달 방법 (아래 중 편한 방법)

1. `Desktop/lipsync-pipeline` 폴더 내용을 이 저장소의 `video/` 아래로 복사해 커밋/푸시
   - 프로세스 정리 파일 → `video/process/`
   - 캐릭터 이미지 → `video/characters/`
   - 완성 영상(용량이 크면 일부 샘플만) → `video/output/`
2. 파일 용량이 큰 경우(영상 등), 클라우드 저장소 링크로 공유해 주셔도 됩니다.

> 용량이 큰 영상 파일을 그대로 git에 올리면 저장소가 무거워집니다.
> 영상 원본은 Git LFS 사용 또는 외부 저장소 링크를 권장하며, 저장소에는
> 샘플·썸네일·설정 파일 위주로 올리는 방식을 제안합니다. (자료 확인 후 확정)

## 폴더 구성 (예정)

```
video/
├── process/       # 작업 프로세스 정리 문서 (순서, 사용 도구, 설정값)
├── characters/    # 캐릭터 이미지 (구도의 기준이 되는 원본)
└── output/        # 완성 영상 또는 샘플
```

## 영상 제작 과정 (자료 확인 전 일반 개요)

아래는 캐릭터 이미지 기반 립싱크 영상의 **일반적인** 단계입니다.
사용자님의 실제 프로세스 파일을 확인한 뒤, 사용하는 도구/설정에 맞게 정확히 다시 작성합니다.

1. **대본 준비** — 영상에서 말할 내용을 글로 작성
2. **음성 준비** — 대본을 음성으로 만들거나 녹음
3. **캐릭터 이미지 준비** — 말하는 주체가 될 캐릭터 이미지 (구도·화면 비율 기준 고정)
4. **립싱크 생성** — 캐릭터 이미지 + 음성으로 입 모양이 맞춰진 영상 생성
5. **편집·자막** — 배경, 자막, 인트로/아웃트로 등 편집
6. **내보내기·업로드** — 유튜브 규격으로 내보내고 업로드

## "같은 구도"를 유지하기 위해 정리할 항목 (자료 확인 후 채움)

새 캐릭터 이미지를 받아도 동일한 구도의 영상을 만들려면 아래 기준값을 문서로 고정해야 합니다.
실제 자료를 받으면 이 표를 실제 수치로 채웁니다.

| 항목 | 예시 | 실제 값 |
| --- | --- | --- |
| 화면 비율 | 16:9 / 9:16 | (확인 필요) |
| 해상도 | 1920×1080 등 | (확인 필요) |
| 캐릭터 위치·크기 | 화면 내 배치 기준 | (확인 필요) |
| 사용 도구/모델 | 립싱크에 쓰는 프로그램·모델명 | (확인 필요) |
| 주요 설정값 | 프레임레이트, 배경 처리 등 | (확인 필요) |
