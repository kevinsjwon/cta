# cta

세무회계 사무소의 온라인 활동을 위한 작업 저장소입니다.
웹사이트와 유튜브 영상 작업을 우선으로 하고, 이후 블로그와 인스타그램 홍보로 확장할 예정입니다.

이 문서는 AI나 개발에 익숙하지 않은 분도 이해할 수 있도록 작성했습니다.

## 목표와 우선순위

현재 우선순위는 아래 두 가지입니다.

1. **세무사무소 웹사이트** — 기획, 제작, 그리고 개업 이후 지속 관리
2. **유튜브 영상** — 캐릭터 이미지 기반 립싱크 영상 제작

위 두 가지가 안정화된 뒤에 진행할 항목입니다.

3. 블로그 홍보 (예정)
4. 인스타그램 홍보 (예정)

## 폴더 구성

```
cta/
├── website/     # 세무사무소 웹사이트 (지금 바로 미리보기 가능)
├── video/       # 유튜브 영상(립싱크) 작업 폴더
└── README.md    # 이 문서
```

각 폴더 안에 자세한 설명 문서(README)가 따로 있습니다.

- 웹사이트 설명 → [`website/README.md`](website/README.md)
- 영상 작업 설명 → [`video/README.md`](video/README.md)

## 지금까지 된 것

- **웹사이트 화면 완성**: 소개, 업무분야, 상담 절차, 상담 문의, 오시는 길 섹션을 갖춘
  반응형(PC·모바일 모두 대응) 웹사이트 기본 화면을 만들었습니다.
  실제 사무소 정보가 들어갈 자리는 대괄호 `[ ]` 로 표시해 두었습니다.
- **프로젝트 구조·문서 정리**: 웹사이트와 영상 작업을 나눠서 관리하도록 폴더와 설명 문서를 만들었습니다.
- **영상 제작 문서 정리**: 업로드된 제작 과정 문서(`PROCESS.md`)와 설정 파일을
  `video/lipsync-pipeline/` 폴더로 정리하고, 비전문가용 쉬운 안내서(README)를 작성했습니다.
- **영상 제작 코드·자료 정리**: 실행 스크립트(`bin/`, 36개), 원본 캐릭터 이미지·대화장면·대본(`closeup/`),
  검수 설정(`input/cast.json`)을 파이프라인이 기대하는 폴더 구조로 정리해 넣었습니다.
  이제 영상을 렌더하는 데 필요한 코드와 자료가 저장소에 모두 갖춰졌습니다.

## 아직 필요한 것

- **웹사이트 실제 정보**: 사무소명, 대표 세무사 이름, 연락처, 주소 등.
  ([`website/README.md`](website/README.md)의 표 참고)
- **영상 렌더 실행 환경**: 코드와 자료는 모두 저장소에 들어와 있습니다. 다만 대사를 음성으로
  읽는 기능이 **맥(macOS)의 한국어 음성(`say`/Yuna)**에 의존하므로, 실제 영상 렌더에는
  맥 환경(또는 다른 TTS로의 교체)이 필요합니다.
  자세한 내용은 [`video/lipsync-pipeline/README.md`](video/lipsync-pipeline/README.md)의
  "2. 지금 이 폴더의 상태"를 참고하세요.

## 웹사이트 미리 보기

컴퓨터에 Python이 설치되어 있다면 아래 명령으로 웹사이트를 볼 수 있습니다.

```bash
cd website
python3 -m http.server 8080
```

웹브라우저 주소창에 `http://localhost:8080` 을 입력하면 화면이 나옵니다.
(종료하려면 터미널에서 `Ctrl + C`)

## 용어 간단 설명

- **저장소(repository)**: 이 프로젝트의 모든 파일을 모아 두고 변경 이력을 관리하는 공간입니다.
- **정적 웹사이트(static site)**: 서버나 데이터베이스 없이 파일만으로 동작하는 웹사이트입니다. 운영 비용이 적고 관리가 쉽습니다.
- **립싱크(lip-sync)**: 음성에 맞춰 캐릭터의 입 모양을 움직이게 하는 것입니다.
- **반응형(responsive)**: 화면 크기(PC·태블릿·휴대폰)에 맞게 배치가 자동으로 바뀌는 것입니다.
