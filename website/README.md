# 세무사무소 웹사이트 (website)

새로 개업하는 세무회계 사무소의 공식 웹사이트입니다.
지금은 **정적 웹사이트(static site)** 형태이며, 별도의 서버나 데이터베이스 없이 파일만으로 동작합니다.

## 폴더 구성

```
website/
├── index.html            # 웹페이지 본문 (모든 내용이 여기에 있음)
├── assets/
│   ├── css/styles.css    # 디자인(색상, 레이아웃, 반응형)
│   ├── js/main.js        # 동작(모바일 메뉴, 문의 폼 처리)
│   └── img/              # 이미지(로고, 사진 등)를 넣는 곳
```

## 지금 상태

- 화면 구성(디자인, 섹션, 반응형)은 완성되어 있습니다.
- 실제 사무소 정보가 들어갈 자리는 대괄호 `[ ]` 로 표시해 두었습니다.
  예: `[사무소명]`, `[대표 세무사 이름]`, `[전화번호]`, `[이메일 주소]`, `[사무소 주소]`
- 아직 확정 정보가 없어 임시 문구를 넣어 두었으며, 과장된 홍보 문구는 넣지 않았습니다.

## 채워 넣어야 할 실제 정보

`index.html` 파일을 열어 아래 대괄호 부분을 실제 값으로 바꾸면 됩니다.

| 표시 | 의미 |
| --- | --- |
| `[사무소명]` | 사무소 이름 |
| `[대표 세무사 이름]` | 대표 세무사 성함 |
| `[지역]` | 사무소가 위치한 지역 |
| `[전화번호]` | 대표 전화번호 |
| `[이메일 주소]` | 상담용 이메일 |
| `[사무소 주소]` | 사무소 도로명 주소 |

## 로컬에서 미리 보는 방법

컴퓨터에 Python이 설치되어 있다면 아래 명령으로 미리 볼 수 있습니다.

```bash
cd website
python3 -m http.server 8080
```

그다음 웹브라우저 주소창에 `http://localhost:8080` 을 입력하면 화면이 나옵니다.
(종료하려면 터미널에서 `Ctrl + C` 를 누릅니다.)

## 아직 연동이 필요한 부분 (추후 작업)

- **상담 문의 폼 실제 전송**: 현재 폼은 화면 확인용입니다. 실제로 문의 내용을 받으려면
  이메일 전송 서비스나 간단한 폼 서비스(예: 폼 전용 SaaS) 연동이 필요합니다.
- **지도**: "오시는 길"은 자리만 잡아 두었습니다. 카카오/네이버 지도 임베드 코드를 넣으면 됩니다.
- **도메인/배포**: 실제 인터넷 주소로 공개하려면 도메인 구입과 배포(호스팅) 설정이 필요합니다.
  정적 사이트이므로 무료/저비용 호스팅으로도 운영할 수 있습니다.

## 앞으로의 유지관리 방향

- 블로그를 붙일 계획이 확정되면, 이 정적 사이트를 그대로 두고 블로그만 별도로 연결할지,
  또는 블로그 기능이 있는 구조로 옮길지 판단이 필요합니다. 이 부분은 블로그 작업 단계에서 다시 정리합니다.
